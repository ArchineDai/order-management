# 订单台账隐私政策页面设计

## 目标

在现有公司官网发布一份可供 Google Play 审核与用户访问的中英双语隐私政策，并使用固定地址 `https://mole.archie-lab.com/privacy/`。

## 方案选择

1. 使用第三方隐私政策托管：上线快，但会引入不必要的第三方依赖，不采用。
2. 在现有公司官网增加独立静态页面：使用现有 HTTPS 域名、联系渠道和部署方式，采用。
3. 将政策附加在公司首页：缺少清晰稳定的政策地址，不采用。

## 页面内容与边界

- 仅适用于“订单台账”应用，提供简体中文与英文等义版本。
- 应用订单、采购、库存、BOM 与附件资料通过设备本地存储保存；应用不经营服务器账户体系，也不会将这些数据自动传输给开发者。
- 相机、相册和文件权限仅在用户主动拍摄、选择凭证或导入资料时使用。
- 用户主动使用系统分享、导出或附件选择功能时，由用户自行决定向何处提供相应内容。
- 应用不展示广告，不销售或共享用户数据，不面向儿童。
- 联系渠道固定为 `contact@archie-lab.com`。
- 页面不作未经证实的加密、认证或合规承诺。

## 实现与部署

- 新增 `website/mole/privacy/index.html`，使用独立静态 HTML 与内联 CSS；默认显示中文，并提供英文切换。
- 页面以可读性为优先，使用与公司官网协调的深色页首、暖金强调色和白色正文区域。
- 通过现有 `mole.archie-lab.com` 静态站点根目录上传 `privacy/index.html`，不修改现有首页或服务器虚拟主机配置。
- 发布后验证 HTTPS 状态、中文默认内容、英文切换和联系邮箱。

## 验收标准

- `https://mole.archie-lab.com/privacy/` 返回 HTTPS 200。
- 页面说明本地存储、权限用途、无广告与不共享数据的边界。
- 中文和英文版本均可直接阅读，且不依赖 JavaScript 才能显示默认中文内容。
- 页面提供 `contact@archie-lab.com` 联系入口。
