# I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Chinese/English localization driven by the user's phone system language, including app display name and generic purchase wording.

**Architecture:** Use `expo-localization` for locale detection and `i18next`/`react-i18next` for runtime strings. Keep translations in `src/i18n/resources.ts`, initialize in `src/i18n/index.ts`, and consume via `useTranslation()`/`t()` in Expo Router screens and shared order components.

**Tech Stack:** Expo SDK 57, React Native 0.86, Expo Router, `expo-localization`, `i18next`, `react-i18next`, Vitest.

## Global Constraints

- Chinese system languages use Simplified Chinese.
- All non-Chinese system languages use English.
- App names are `订单台账` and `Order Ledger`.
- UI copy must not mention Taobao; use generic supplier/online purchase wording.
- CSV/import Chinese compatibility remains unchanged in this iteration.
