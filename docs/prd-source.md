# 订单管理 App 1.2.0 PRD

## 目标

本版本将订单管理从单页录入工具升级为多模块经营管理应用。核心目标是让用户可以通过 Excel/CSV 快速导入客户订单，围绕订单、采购、库存、BOM 和利润统计完成日常查询、跟进和复盘。

## 范围

### 底部六个模块

1. 首页：展示关键待办和经营概览入口。
2. 订单管理：管理所有订单及多行物料明细，支持按物料名称、规格型号搜索。
3. 采购管理：管理订单行对应的采购记录，支持按物料名称、规格型号、买入规格搜索。
4. 库存管理：按规格型号汇总采购折算数量、已送数量、库存结余和欠货数量。
5. BOM：维护成品和组件关系，一个成品可包含多个组件，并记录成品采购成本。
6. 我的：展示利润统计，包括总订单数、销售额、采购成本、总利润、本月订单数、本月利润、月销售趋势和月利润趋势。

### 订单管理分类

- 全部：所有订单。
- 未发货：订单所有行均未发货。
- 部分发货：存在发货记录，但订单未全部发完。
- 已发货：订单所有行已发货，且未被标记完成。
- 已完成：订单已被业务闭环标记完成。

### 采购管理分类

- 已开票：采购记录标记为需要或已归类为开票状态。
- 未开票：采购记录未归类为已开票状态。

### 库存管理分类

- 零库存：库存结余为 0 且无欠货。
- 有库存：库存结余大于 0。
- 欠货：未发数量大于 0 或库存结余小于 0。

## 业务规则

### Excel/CSV 导入替代 OCR

- 本版本移除 OCR 录入入口和 OCR 作为主流程的产品要求。
- 新增 Excel/CSV 导入入口；CSV 以文本解析，Excel 读取首个工作表并转换为订单导入数据。
- 导入行需自动识别常见中文和英文表头：公司名称、订单日期、客户 PO 号、物料名称、规格型号、数量、单位、含税单价、价税合计。
- 当价税合计为空时，系统按 `数量 * 含税单价` 自动计算，并保留两位小数。
- 相同 `公司名称 + 订单日期 + 客户 PO 号` 的导入行合并为一个多行订单。
- 导入结果必须生成与现有订单创建逻辑兼容的订单输入结构。

### 输入历史自动补全

- 公司名称、物料名称、规格型号、买入规格、供应商、买入单位等输入项应提供历史建议。
- 建议来源包括历史订单、历史采购记录和 BOM 成品/组件。
- 建议去重后按最近使用时间优先排序；输入关键字时按包含匹配过滤。

### BOM

- BOM 记录成品物料名称、成品规格型号、成品采购成本、组件列表、创建时间和更新时间。
- 组件包含物料名称、规格型号和单个成品所需数量。
- BOM 可编辑；编辑时保留创建时间并刷新更新时间。
- 按成品数量展开 BOM 时，组件数量和成品采购成本按数量倍增。

### 利润统计

- 销售额来自订单行价税合计。
- 采购成本来自订单行关联采购记录的买入总价。
- 总利润为销售额减采购成本。
- 本月订单数和本月利润按订单日期所在月份统计。
- 月销售趋势和月利润趋势按 `YYYY-MM` 聚合并按月份升序输出。

## 非本版本范围

- 不新增 React Native 或 Expo 依赖到领域层。
- 不自动把采购资料导入并匹配到既有订单行；采购记录仍通过订单物料的买入入口维护。
- 不实现云端多人同步、权限角色或后端数据库。

## 验收标准

- CSV/Excel 导入能识别常见中英文表头，缺失价税合计时自动计算，并按 `公司名称 + 订单日期 + 客户 PO 号` 合并多行订单。
- 应用通过多页面路由提供首页、订单管理、采购管理、库存管理、BOM 清单、我的 6 个底部模块。
- 订单、采购、库存、BOM 模块均有纯函数支持按物料名称或规格型号搜索。
- 订单管理分类能区分全部、未发货、部分发货、已发货、已完成。
- 采购管理分类能区分已开票和未开票。
- 库存管理分类能区分零库存、有库存和欠货。
- BOM 类型和纯函数支持成品多组件、成品采购成本、编辑保存和数量展开。
- 利润统计能输出总订单数、销售额、采购成本、总利润、本月订单数、本月利润、月销售趋势和月利润趋势。
- 旧订单数据在没有完成时间、BOM 或导入元数据时仍可正常读取。
- `pnpm test` 和 `pnpm typecheck` 均通过。
